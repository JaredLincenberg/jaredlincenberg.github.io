# jaredlincenberg.github.io

Personal website and blog for Jared Lincenberg — built with [Jekyll](https://jekyllrb.com/) and hosted on [GitHub Pages](https://pages.github.com/) at [jaredlincenberg.github.io](https://jaredlincenberg.github.io).

## Branching

- `main` — the stable, published branch. GitHub Pages builds the live site from here.
- `post/<slug>` — one short-lived branch per post or page in progress, branched off `main` and merged back in directly once it's ready to publish.

## Related projects

When a post or page involves building or reusing standalone code — a tool, script, or small project rather than site content — that code lives in its own repository instead of here. It's linked from this README, and from the blog post that introduces it where relevant.

- [iNaturalist Biodiversity](https://github.com/JaredLincenberg/iNaturalist-Biodiversity) — [live site](https://jaredlincenberg.github.io/iNaturalist-Biodiversity/)
